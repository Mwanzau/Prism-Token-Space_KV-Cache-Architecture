# Prism-Token-Space_KV-Cache-Architecture
The Prism Token-Space_KV-Cache Architecture is an improvement of RAG on Edge devices, it removes the overhead of the model querying the document(s) everytime it needs an answer. The end result is an architecture that suggests a second brain for the AI model itself. As long as the AI model can speak a language and act, all we need is to add knwldge.
